    ℹ️ حول النظام

    🏥 نظام مراقبة كبار السن للكشف عن السقوط

    نظام ذكي يعتمد على الرؤية الحاسوبية والذكاء الاصطناعي لمراقبة كبار السن والكشف الفوري عن حالات السقوط. يدعم تحليل الصور والفيديو والكاميرا المباشرة، ويرسل إشعارات تيليغرام فورية عند اكتشاف سقوط أو وضعية خطرة.

    🤖 كيف يعمل النظام:

    1️⃣ يلتقط الكاميرا أو الصورة أو الفيديو

    2️⃣ يحدد الهيكل العظمي والمفاصل (تتبع 33 نقطة للجسم) عبر MediaPipe Pose

    3️⃣ يحلل ويصنّف الوضعية باستخدام الذكاء الاصطناعي: جلوس / وقوف / سقوط

    4️⃣ عند اكتشاف سقوط يرسل تنبيهاً فورياً على تيليغرام

    🤖 الخوارزمية والنموذج: MediaPipe Pose (لتتبع المفاصل) + MobileNetV2 (CNN)

    📊 الفئات المصنّفة: وقوف — جلوس — سقوط

    🎯 دقة النموذج: أكثر من 95%

    🌐 تقنيات التطوير: Python · Flask · TensorFlow · OpenCV · MediaPipe JS

    👩‍💻 المطورة: فرح هاشم عبد

    🎓 الجهة: جامعة التكنولوجيا — كلية علوم الحاسوب / قسم الذكاء الاصطناعي

    📅 إصدار: 2026

    🎧 الدعم الفني

    كيف يمكننا مساعدتك؟

    📌 الاستخدام الأساسي:

    • رفع صورة: اختر وضع "رفع ملف" وارفع صورة أو فيديو للشخص

    • كاميرا مباشرة: اختر "مراقبة بالكاميرا" واضغط تشغيل للمراقبة الفورية

    • تنبيه تيليغرام: أدخل Token و Chat ID من الإعدادات أسفل الصفحة

    ⚠️ إذا لم تعمل الكاميرا:

    • تأكدي أن الموقع يعمل عبر HTTPS

    • اضغطي "السماح" عند طلب إذن الكاميرا من المتصفح

    📧 للتواصل: يرجى التواصل مع المطورة عبر الجامعة

    🔒 سياسة الخصوصية

    حماية بياناتك أولويتنا

    📸 الصور والفيديوهات المرفوعة:
    يتم تحليلها فورياً ثم حذفها تلقائياً من السيرفر. لا يتم تخزين أي صور.

    📱 بيانات تيليغرام:
    يتم حفظ Bot Token و Chat ID على السيرفر الخاص بك فقط ولا يتم مشاركتها مع أي جهة.

    🎥 الكاميرا المباشرة:
    بث الكاميرا يُعالج محلياً في المتصفح ويُرسل فريم واحد كل ثانية للتحليل فقط. لا يتم تسجيل الفيديو أو تخزينه.

    لا يستخدم هذا النظام أي ملفات تتبع أو إعلانات.
